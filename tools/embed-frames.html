Sematkan frame

Supaya website bisa dibuka langsung (double-click index.html) dan tetap bisa download, tanpa server.

  1. Pilih semua file frame (frame1.png sampai frame5.png).
  2. Klik Download frames-data.js.
  3. Simpan ke folder js/ dan timpa frames-data.js yang lama.

    Ulangi langkah ini setiap kali ada frame yang diganti. Nama file harus sama dengan yang didaftarkan di js/config.js.
